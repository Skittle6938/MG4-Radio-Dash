**This update downloads about 8.6 MB of data: better on Wi-Fi from a phone hotspot, or over USB if possible.**

**Radio Dash 1.6.3 beta 2**

- **RDS station name in MG4Dash**: the stock radio only puts in its media session the RDS name known when it tunes, nearly always empty since the name arrives a few seconds later, so the MG4Dash music card kept the frequency as the station name. Radio Dash now sends MG4Dash the name it receives, with the station's frequency: the name shows as the title, the frequency below. Needs MG4Dash 1.7.3 beta 18 or later.
- **Left bar like MG4Dash's when the fog light button is hidden**: with MG4Dash's new *Shortcuts menu* option (which hides MG's fog light button), the vertical bar on the left takes the full height, as in MG4Dash. Without it, the space at the top left stays as before.

Install from MG4Dash (Settings > System > Update > Update Radio Dash, with beta versions on), or like before (`adb push` + `pm install -r -f`, or USB stick), then **reboot the head unit** (hold Home about 20 s): the steering wheel buttons don't reach the radio until you do.
